# Wagara 和柄

All ten patterns, default band (`height: 56`, `scale: 1`). The three marked
**heavy** lay down 44–50% ink — print them a step below your usual
`--density`.

### asanoha 麻の葉 — hemp-leaf star lattice

```wagara asanoha
```

### ichimatsu 市松 — checkerboard (heavy)

```wagara ichimatsu
```

### kanoko 鹿の子 — fawn spots, a shibori dapple

```wagara kanoko
```

### kikkou 亀甲 — tortoise-shell hexagons

```wagara kikkou
```

### sayagata 紗綾形 — key fret of linked 卍

```wagara sayagata
```

### seigaiha 青海波 — overlapping "blue sea waves"

```wagara seigaiha
```

### shippou 七宝 — interlocking "seven treasures" circles

```wagara shippou
```

### tatewaku 立涌 — rising steam

```wagara tatewaku
```

### uroko 鱗 — fish scales (heavy)

```wagara uroko
```

### yagasuri 矢絣 — arrow fletching (heavy)

```wagara yagasuri
```

## Scale

The same motif at `scale: 1`, `2`, and `4` — seigaiha, taller band so the
big fans fit:

```wagara seigaiha
height: 96
```

```wagara seigaiha
height: 96
scale: 2
```

```wagara seigaiha
height: 96
scale: 4
```
